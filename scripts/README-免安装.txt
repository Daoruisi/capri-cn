一、这是什么
   Capri 是一个会待在你桌面上的同人桌宠：能聊天、能说话、能陪你
   打游戏，也会爬到窗口上、底边或者图标上待着。这个 zip 是汉化分支
   的免安装版：解压就能用，不用安装程序，也不需要管理员权限。

   和安装版（Capri-Setup.exe）功能一样，区别只有：
   - 免安装版不会默认开机启动，需要的话在主控台里自己打开；
   - 免安装版的数据同样放在 %LOCALAPPDATA%\Capri，卸载时手动删
     这个文件夹即可（见第五节）；
   - 想让通话里的朋友听到她，需要装 VB-CABLE 虚拟声卡。她自带
     驱动包，在设置里按提示装就行（会弹一次管理员确认）。

二、运行环境
   - Windows 10 或 Windows 11，64 位（x64）；
   - 不需要另外装 .NET 或运行库；
   - 用云端大脑/云端语音时要联网；本地大脑和本地音色/耳朵第一次
     下载也要联网，配好之后可以离线使用；
   - 建议单独解压到一个文件夹（比如 D:\Capri），不要放进
     C:\Program Files 这类需要管理员权限的目录；
   - 同一时间只运行一个 Capri。

三、第一次运行（三步）
   1. 解压 zip，双击 Capri.exe。
      新版 Windows 可能弹 SmartScreen「Windows 已保护你的电脑」：
      点「更多信息」→「仍要运行」。
   2. 在她的主控台（Capri Mainframe）点「设置她的脑子」
      （Set up her brain），或者点「免费 Key」用 NVIDIA 免费 Key；
      也可以填自己的 DeepSeek / OpenAI / Claude 等 Key。
   3. 想让她说话，在 VOICE 里选音色。汉化分支默认开着「中文台词
      英文配音」：免费音色只会英语，所以中文台词会自动先翻成英文
      再念出来，屏幕上显示的仍然是中文原话。

   聊天框：点她旁边的铅笔图标打字，波浪图标是语音聊天；
   右键她或托盘图标可以打开菜单和主控台。

四、你的数据存在哪
   全部在：%LOCALAPPDATA%\Capri
   （在资源管理器地址栏粘贴这行再回车就能打开）

   里面包括设置、聊天记忆、人格文件 personality.md、日志
   errors.txt，以及下载到本地的语音/耳朵/大脑模型文件。
   换电脑或重装前想保留记忆，备份这个文件夹即可。

五、怎么彻底卸载（免安装版）
   1. 右键托盘图标 → 退出（或者在主控台里退出）；
   2. 如果开过「开机启动」，先在主控台里关掉；
   3. 删掉你解压出来的整个文件夹；
   4. 删掉 %LOCALAPPDATA%\Capri
      （这会清掉设置、记忆、聊天记录和 Key；只想清程序、想保留
      记忆的话这一步可以跳过）；
   5. 如果装过 VB-CABLE 虚拟声卡，在「设置 → 应用 → 安装的应用」
      里把 VB-CABLE 卸载，再重启一次电脑。
   做完这 5 步，机器上就没有她的残留了（免安装版不写注册表卸载项，
   只有你手动开「开机启动」时会写一个启动项）。

六、杀毒软件 / SmartScreen 提示
   - 她是一个没有代码签名证书的免费同人项目。exe 新、下载量少，
     杀毒软件（360、火绒、Defender 等）和 SmartScreen 很容易按
     启发式误报，这是常见现象，不是 zip 坏了。
   - 只从本仓库的 Releases 页面下载 zip，不要用来路不明的网盘
     或第三方下载站的文件。
   - 想核对文件，在 PowerShell 里执行：
       Get-FileHash .\{{ZIPNAME}} -Algorithm SHA256
     和发布页给出的 SHA256 对比，一致就说明文件没被改过。
   - SmartScreen：点「更多信息」→「仍要运行」。
   - 杀软拦截：确认来源可信后，把解压目录加进信任区/白名单；
     不要为了跑她关掉杀软的整体防护。

七、升级
   免安装版的升级方式：下载新版 zip，把新的 Capri.exe 覆盖到旧
   文件夹即可，数据在 %LOCALAPPDATA%\Capri，不受影响。
   程序里的「自动更新」是给安装版设计的；免安装版用它会被装到
   %LOCALAPPDATA%\Capri（相当于变成安装版）。想保持免安装，就
   手动下载新版覆盖。

八、汉化分支额外加的东西
   - 4 套立绘：原版 / 清晰 / 像素 / 动漫，右键 →「立绘」切换；
   - 随机换装：主控台打开「随机换装立绘」，可填间隔（分钟）和
     每套停留（秒）；到点随机换一套，停一会儿再回到你选的那套；
   - 开屏动画：启动时先播约 1.3 秒的接入动画；
   - DSH 状态桥：配合 DSH 的 capri-bridge 插件，任务跑完她会播报，
     需要你批准时先喊你，还会报本轮 token；
   - 右键「查余额」：Key 是 DeepSeek 时可以直接查剩余余额；
   - DeepSeek 看图：DeepSeek V4/Flash 这类接口本来就能收图，上游
     按纯文本模型处理，这里放开了「看屏幕」能力；
   - 中文台词英文配音：见第三节第 3 条。

   - 先看 %LOCALAPPDATA%\Capri\errors.txt 里的报错；
   - 上游帮助：https://capriai.app/help/
     上游 Discord：https://discord.gg/capridesktop
